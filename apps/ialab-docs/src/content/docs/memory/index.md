## Qué contiene

- **Qdrant Memory Layer**: colecciones reales, roles y governance.
- **Episodic memory**: estado vivo local (no versionado).
- **Incident memory**: recall orientado a incidentes.
- **Cognitive history**: trazas cognitivas para análisis y calidad.

Regla: la memoria es **complementaria**; no reemplaza autoridad (Prometheus) ni operational truth.
